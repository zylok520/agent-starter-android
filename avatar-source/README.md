# 人物参考素材

`portrait-cutout.png` 是根据用户提供的照片，通过 imagegen 去除背景得到的 RGBA 人物素材（940 × 1672）。它是 AI 编辑结果，需以原始照片为准复核人物细节。不是三维模型，也不包含嘴型或眨眼绑定。

该透明素材保留作为建模参考。App 现已切换到参考照片特征制作的卡通 GLB（`app/src/main/assets/models/portrait-avatar.glb`），并未把照片当成三维贴片。实际网格的中性、说话、闭眼和背面预览见 `portrait-3d-preview.png`。

## 若制作完整 3D 人物

以原始照片和本目录透明图作为人物外观参考；单视角不可见的侧面、后脑、口腔和眼睑结构需要建模补全，不能声称是精确重建。

当前 Filament 原型的模型交付约定：

- glTF 2.0 二进制 GLB，嵌入所需贴图；Y 向上，人物正面朝 +Z。
- 正常状态睁眼、闭嘴，嘴部带真实可变形几何及口腔内侧。
- 当前加载器读取各网格 `extras.targetNames` 的第 0 项：嘴型为 `mouthOpen`，眨眼为 `blink`，权重范围 0–1。
- 若正式模型在同一网格包含多个表情，需先将加载器改为按名称查找所有索引，不能直接套用当前第 0 项约定。
- 替换时检查人物比例、相机位置、材质、头发透明效果和手机性能。

若选择照片形象优先的 2.5D 路线，则需要制作正面嘴型／眼睑状态或可变形网格，限制转头范围；这种结果不能作为完整三维人物交付。
