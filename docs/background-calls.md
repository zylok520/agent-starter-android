# 锁屏通话与无回复超时

通话在麦克风权限获准、界面处于前台时启动 microphone 前台服务。服务持有部分唤醒锁，让息屏后的音频连接和计时继续运行；通知提供返回通话和挂断入口。Android 13 及以上会请求通知权限，拒绝不阻止通话，但通知栏中的挂断入口可能不可见。

## 计时规则

- 正常通话保持屏幕常亮；手动锁屏后仍可语音对话。
- 用户发出文字消息或语音提问后开始等待回复。继续说话、再次提问会重新计时。
- 收到 Agent 的非空文字、转写、说话状态或音频活动时，取消等待计时。纯粹空闲、不提问不触发无回复挂断。
- 等待回复达到 5 分钟后取消屏幕常亮。普通 App 不主动调用设备管理接口强制锁屏，因此实际息屏时间还受系统屏幕超时设置影响。
- 超时后，检测到息屏或系统锁定，开始第二段 5 分钟计时；持续无回复才挂断。提前手动锁屏不会缩短第一段等待时间。
- 收到回复、再次提问会取消或重置倒计时；解锁后取消第二段计时。网络重连由 LiveKit 处理，没有额外增加 30 秒断网挂断规则。
- 退到后台或锁屏时关闭摄像头和屏幕共享，返回后需手动重新开启。
- 界面重建不主动挂断。返回键、挂断按钮、通知挂断、移除最近任务、最终断线都会结束通话并释放服务和唤醒锁。进程被系统终止后不自动重启麦克风。

时间常量集中在 `CallTimeoutPolicy`；后台服务使用单调时钟，不受修改系统时间影响。

## 验证

`CallTimeoutPolicyTest` 覆盖正常静默、两段计时边界、提前锁屏、锁屏收到回复、新问题、解锁重置，6 项独立 JVM 测试通过。

本机 Android 构建被 Gradle 的 `Unable to establish loopback connection` 阻挡，尚未完成完整编译或真机验收。

真机验收至少覆盖：

1. 授予麦克风权限后开始通话，按电源键锁屏，验证双方音频。
2. 用不回复的测试 Agent，验证提问 5 分钟后允许息屏，实际息屏再过 5 分钟挂断。
3. 第二段计时中让 Agent 回复，确认继续通话；再测试新提问及解锁。
4. 正常长回复和未提问的静默，不应触发无响应挂断。
5. 锁屏通知挂断、系统返回键、移除最近任务后，检查麦克风指示及通知消失。
6. 旋转屏幕、切后台再返回、拒绝通知权限、断网重连、摄像头和屏幕共享中锁屏。

Android 前台麦克风服务限制参考：[官方文档](https://developer.android.com/develop/background-work/services/fgs/service-types#microphone)。实际后台存活还需在目标手机上验证。
